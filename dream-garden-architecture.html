🌱 Dream Garden

A gamified personal development platform for cultivating ideas into launched products

Vision: Users plant "seeds" (ideas), nurture them through learning (CBT, mindfulness, business, coding), and harvest outcomes (launched products/services).

MVP Scope (Phase 1)

Focus on core loop before expanding:

  • User registration/login with JWT
  • Create garden and plant seeds
  • Basic task system with manual completion
  • XP and streak tracking
  • Simple CBT thought record exercise
  • Basic mindfulness timer
  • REST API with simple web client

Estimated Timeline: 8-10 weeks for solo developer
